# Speech Emotion Recognition Notebook

This notebook is part of the Speech Emotion Recognition (SER) project.

## What this file is

This notebook is used for exploring and experimenting with the speech emotion recognition workflow, including:

- loading and inspecting audio data
- extracting audio features such as MFCCs
- testing emotion classification approaches
- validating the model ideas used in the main Streamlit app

## How it relates to the project

The notebook is a research and development companion to the app files:

- Web.py — main user interface
- Webfunc.py — model prediction helpers
- feature.py — feature extraction and preprocessing

It helps demonstrate how the audio processing and model logic are developed before being integrated into the app.

## Typical use

Use this notebook to:

1. understand the audio preprocessing steps
2. test feature extraction methods
3. experiment with model behavior
4. reference the training or analysis flow used in the project

## Notes

This notebook is not the main application itself; it is an analysis and experimentation file that supports the SER project.
